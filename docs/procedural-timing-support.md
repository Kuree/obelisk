# Procedural timing support

This matrix records the executable boundary implemented by the current
vertical slices. “Executable” means the checked source subset lowers through
both native and bytecode tiers with differential trace coverage. It does not
mean that the umbrella IEEE 1800 procedural-synchronization work is complete.

| Form | Current boundary |
| --- | --- |
| Integral `#delay` | Executable for constant and dynamic packed integral expressions up to 64 bits; X/Z and negative values normalize to zero. Static overflow is diagnosed and dynamic scaling is range-checked identically in native and bytecode. |
| Real/realtime delay | Executable for literals and dynamic binary32/binary64 expressions, including unary sign; values round at lexical `timeprecision` before design-precision scaling. |
| `#0` | Executable in Inactive for design-domain processes and Re-Inactive for program-domain processes. Native and design-bytecode work share the same region/rank/insertion ordering key. |
| `#1step` | Executable as one design-precision tick. |
| Direct signal event | Executable for statically addressable signal/net expressions and change/posedge/negedge/both-edge. Real-valued change events use IEEE equality (`+0.0` and `-0.0` are equal; every NaN publication changes). Vector edges observe only the edge-defining bit. A directly addressable `iff` value is sampled and latched at the primary occurrence. |
| Event list | Executable for direct and computed signal/net members, including mixed lists and computed or mixed `iff` conditions. All-direct lists retain the handle-based fast path; a list containing a computed member uses source-ordered observers. A single named event retains the direct-event path. |
| Computed event expression | Executable for change/posedge/negedge/both-edge controls, four-state values, vector LSB edge rules, dynamic selections, and transient same-fragment occurrences. Dependencies watch complete root objects plus dynamic index inputs so retargeting cannot leave stale subscriptions. |
| `@*` | Executable for dependencies discovered from lowered controlled-statement reads and transitive zero-time callee read summaries; write-only captures are excluded. |
| Repeated event control | Executable, including zero and dynamic counts. |
| `wait (expr)` | Executable for constants, directly addressable packed values, and computed expressions. A true occurrence is latched at the relevant publication, including same-fragment transients. Computed evaluators support the executable zero-time expression and call subset. |
| Concurrent assertion cycle delays | Executable as compiler-generated bounded AOT state for `assert property`, `assume property`, `cover property`, `cover sequence`, and simulation-silent `restrict property`, with fixed `##N`, small bounded `##[M:N]`, and finite positive consecutive `[*N]` / `[*M:N]` repetition over a horizon of at most 63 clock samples and 256 exact traces. Unbounded, empty-match, nonconsecutive, goto, and dynamic timing forms are rejected rather than truncated or committed at an arbitrary endpoint. |
| Static named event | Executable for fresh uninitialized design events, direct waits/triggers, equality, and `.triggered`, including computed reads such as `wait (event.triggered)`. |
| Event initialization/assignment/null | Rejected pending event cells, nullable handles, and automatic event lifetime. |
| Blocking `->` | Executable for supported static named events. |
| Nonblocking `->>` | Executable with optional integral delay through scheduler-owned event commits. Commits use NBA for design-domain callers and Re-NBA for program-domain callers. |
| `$strobe` family | Executable as one-shot Postponed processes. Arguments are re-evaluated after same-slot NBA/Re-NBA commits, and strobes complete before final blocks. |
| `$monitor` family | Executable as one context-wide persistent Postponed process, including replacement by a later `$monitor`, once-per-changed-slot output, and `$monitoron`/`$monitoroff`. |
| `wait_order` | Imported with unambiguous inventory, then rejected with a targeted occurrence-order diagnostic. |
| Blocking intra-assignment timing | Executable for delay, direct event, and repeated-event controls. RHS is captured at encounter; LHS is resolved at commit. |
| Nonblocking intra-assignment timing | Executable for delay controls with encounter-time LHS/RHS capture. Event/repeat controls remain pending deferred actions. |
| Immediate assertions | Ordinary `assert`, `assume`, and `cover` lower to control flow with four-state truth semantics, explicit action blocks, and source-qualified default diagnostics for failed `assert` and `assume`. Deferred `#0`/`final` expressions are evaluated when encountered; named action inputs are captured by value. Reports use ticketed per-process/site replacement so only the last same-slot result matures. `#0` reports mature in Observed and explicit actions are spawned in Reactive; `final` reports and actions execute in read-only Postponed. Pending reports are flushed when their process resumes after a delay or event wait (including `always_comb`/`always_latch` reactivation) and when its outermost enclosing process scope is disabled; disabling a nested scope preserves them. Labeled deferred assertions carry their prepared assertion identity into the ticket queue, so disabling one cancels only that assertion's pending reports. `$assertcontrol` actions 1 through 11 and all assertion-control convenience tasks support fixed type/directive masks plus global, module-instance, and exact-assertion selection for immediate assertions. Off preserves queued reports, Kill cancels matching reports, Lock protects current control state, and deferred attempts snapshot pass/fail action enablement at encounter. Immediate successes are nonvacuous, so NonvacuousOn enables their pass actions while VacuousOff leaves them unchanged. Controls that select concurrent assertions, dynamic arguments, or unsupported scopes are rejected. Full subroutine-argument expression capture and a public assertion-statistics/query API remain pending. |
| Concurrent assertions | A bounded AOT-compiled slice is executable for `assert property`, `assume property`, `cover property`, `cover sequence`, and simulation-silent `restrict property`, with resolved default or explicit direct edge clocks, boolean sampled terms, fixed `##N`, small bounded `##[M:N]`, finite positive consecutive repetition, common positive finite `[->M:N]` / `[=M:N]` repetition with a deterministic prefix and optional one-term `##1` continuation, bounded `and`/`or`/`intersect`/`throughout`/`within`, deterministic one-cycle property `not`/`iff`/`implies`, bounded conditional `if`/`else` and ordinary case-equality `case` properties, fixed `nexttime` / `s_nexttime`, explicitly finite-range `always` / `s_always` / `eventually` / `s_eventually`, one bounded `first_match` priority group at top level or before a continuation, and deterministic bounded-antecedent overlapped/nonoverlapped implication within a combined 63-sample horizon. Persistent repetition uses an O(N) aggregate token DFA rather than one process per live attempt, and counted Reactive dispatch preserves action multiplicity. Compiler-side Z3 minimizes equivalent same-endpoint boolean traces before SSA generation; it is protected for the single-threaded compiler build and never enters generated code or runtime state. The leading-`##1` form may cross direct clocks through further fixed `##1` stages; every source-clock start creates an independent attempt and each destination stage samples at its nearest strictly subsequent clock tick. Branching expansion is capped at 256 exact traces and currently excludes locals, match items, implication, `disable iff`, and `expect`; branching `cover sequence` retains every live alternative and schedules its action once per successful endpoint. Predicates read the canonical Preponed snapshot and deterministic monitor state advances in Observed; explicit pass/fail actions and default `assert`/`assume` failures run as ordered detached Reactive callbacks. Cover implication and conditionals/cases without fallback branches report only nonvacuous cover hits. Explicit and resolved default `disable iff` expressions over static design state are unsampled asynchronous observers: a true transition clears live bounded attempts, blocks starts while true, and invalidates queued same-slot callbacks; X/Z is not true. Statically spawned Observed monitors are native-AOT eligible, while forced AOT honestly retains the generic hybrid coordinator for cold Reactive reports and disable observers. Procedural `expect` supports a one-shot fixed-sequence subset and resumes its caller in Reactive. Automatic disable operands, unbounded timing, strong/weak completion when simulation ends before a bounded trace, general persistent-repetition composition, branching implication antecedents, an immediate first multi-clock term, `##0` or composed multi-clock expressions, recursive or parameterized assertion instances, branching assertion locals, and dynamic timing remain targeted diagnostics. The monitor is ordinary verified simulation SSA with no runtime temporal interpreter or solver dependency. Labeled assertions preserve a stable path/ID for future assertion control without entering a procedural named-block activation. |
| Sampled-value functions | `$sampled`, `$past`, `$rose`, `$fell`, `$stable`, and `$changed` execute for statically addressable packed storage in a procedurally clocked process. The compiler coalesces referenced canonical bit ranges, the runtime copies only those ranges once in Preponed, and compiler-assigned per-logical-process bounded rings retain history; `$past` supports a constant positive depth and a statically addressable gating expression. Concurrent-property predicates may use a direct alternate edge clock, including a direct `iff` condition; alternate-clock history is updated in Postponed so reads in Observed select strictly prior clock occurrences. A simultaneous `$past` gate and explicit-clock `iff`, plus automatic or computed operands, remain targeted diagnostics. |
| `fork` / join forms | Executable for `join`, `join_any`, and `join_none`, including empty forks, automatic declaration capture, nested descendants, and `join_none` spawned from a zero-time function. Other fork forms in a zero-time function are rejected because they can block. |
| `wait fork` / `disable fork` | Executable through the logical-process descendant registry. `wait fork` observes outstanding descendants and `disable fork` recursively cancels the current process's live descendants without affecting unrelated processes. |
| Named block disable | Executable for lexical, named-fork, and resolved hierarchical targets. Cancellation propagates through nested task calls and suppresses pending task copy-out. |
| Timed/recursive task calls | Executable for direct static and automatic tasks with value, output, inout, and ref formals, early return, suspension, direct and mutual recursion, and cancellation. Class tasks use the same suspension-capable call path. Functions remain zero-time, except that they may launch `join_none` children. |
| Module/program domain | Executable with Design/Active and Program/Reactive homes. Assertion evaluators additionally use Design/Observed, assertion action callbacks use Design/Reactive, and final deferred assertions use Design/Postponed. `#0` maps to Inactive/Re-Inactive and nonblocking commits map to NBA/Re-NBA. Region, rank, and insertion sequence form one shared native/bytecode ordering key. |

The umbrella is complete only when the pending rows are implemented and the
native, bytecode, mixed-tier, region-ordering, and leak conformance matrix is
green. Cancellation is executable for the current fork, task, and named-block
surface and remains a required regression dimension as new suspending forms
are added.

The runtime materializes eight executable ordinals: Active, Inactive, NBA,
Observed, Reactive, Re-Inactive, Re-NBA, and Postponed. Preponed is a
time-slot-boundary hook; the eight PLI callback regions remain compiler enum
points and fold exactly while the runtime has no VPI callback producer.

Computed observers run under the waiting logical process and sample `iff` only
after a matching primary occurrence. Signal, resolved-net, NBA, named-event,
and external publications all participate in the same recursive execution
transaction; nested observer writes are evaluated synchronously and bounded by
the runtime resource limit. Native and whole-design bytecode use the same
serialized capture/result contract.
